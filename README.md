# 黃琪婷．作品集 — GitHub Pages 版本

已從 WordPress Gallery 靜態化，不需要 PHP、MySQL 或 WordPress 主機。

## 部署
1. 建立 GitHub repository。若要使用 `https://你的帳號.github.io/`，repo 名稱設為 `你的帳號.github.io`。
2. 上傳本資料夾內所有檔案到 repo 根目錄。
3. Settings → Pages → Deploy from a branch → `main` / `(root)`。

目前包含 64 個 Gallery 實際使用的原始作品檔，保留原站順序、標題、說明、分類與圖片預覽。
