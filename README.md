# hCtPortfolio — GitHub Pages static version

這份版本是依照原 Hostinger / WordPress 作品集頁面重新靜態化，重點不是只搬內容，而是保留原站的視覺與互動設定：

- Elegant Portfolio / Perfect Portfolio 的頁面外框、背景與字體層級
- Portfolio Filter Gallery 的 3 欄 / 2 欄配置與平滑篩選位移
- 原圖自然比例（不裁成正方形）
- 原本 `hvr-sink` 圖片 hover
- 原站使用的 Lightbox2 / LD Lightbox 動畫與操作方式
- 原作品順序、分類、標題與描述

## GitHub Pages

把本資料夾內所有檔案放在 `hCtPortfolio` repository 根目錄：

- `index.html`
- `css/`
- `js/`
- `assets/`
- `portfolio-manifest.json`

然後到 GitHub：Settings → Pages → Deploy from a branch → `main` / `/(root)`。
